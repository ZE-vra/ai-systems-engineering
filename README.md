# AI Systems Engineering

A six-year journey toward mastering software engineering, computer science,
AI systems architecture, machine learning, and AI research and development.

## 🎯 Mission

My goal is to develop the knowledge and practical skills required to design,
build, evaluate, and maintain complex intelligent systems.

I want to understand not only how to use existing AI models and tools, but
also how they work, how to train and improve models, and how to investigate
new approaches to solving difficult problems.

The long-term objective is to become capable of building useful, reliable,
and sophisticated AI-powered systems from the ground up.

## 🧭 Learning Roadmap

This roadmap is a working plan. Progress will be determined by demonstrated
understanding and practical ability, not simply by the passage of time.

### Year 1 — Programming and Computer Science Foundations

- Strengthen Python programming.
- Learn object-oriented programming and software design.
- Study data structures and algorithms.
- Practise Git, testing, debugging, and documentation.
- Learn SQL and relational databases.
- Develop mathematical and logical foundations.
- Build small, complete software projects.

### Year 2 — Software Engineering

- Build backend applications and APIs.
- Study database design and performance.
- Learn authentication, authorization, and application security.
- Practise automated testing and continuous integration.
- Learn Linux, Docker, deployment, and application monitoring.
- Develop stronger probability, statistics, and linear algebra foundations.

### Year 3 — Systems Engineering

- Study operating systems and computer networking.
- Learn concurrency and parallelism.
- Explore distributed systems and system reliability.
- Understand database internals and performance.
- Practise designing maintainable, scalable software.
- Improve existing projects using measurable reliability and performance goals.

### Year 4 — Machine Learning and AI Systems

- Learn fundamental machine learning algorithms.
- Study model training, evaluation, and generalization.
- Learn neural networks and automatic differentiation.
- Explore embeddings, retrieval, tool use, memory, and AI evaluation.
- Build intelligent systems with measurable performance criteria.

### Year 5 — Advanced AI Engineering

- Study deep learning and transformer architectures.
- Experiment with model adaptation and fine-tuning.
- Explore inference performance and model serving.
- Investigate intelligent agents and multimodal systems.
- Read and reproduce selected AI research papers.
- Compare approaches through controlled experiments.

### Year 6 — Specialization and Research

- Select a specialization based on demonstrated interests and abilities.
- Build a substantial AI engineering or research project.
- Reproduce and extend an existing research result where feasible.
- Develop expertise in evaluating, designing, and improving intelligent systems.
- Investigate opportunities to turn useful technical work into real products.

## 🛠️ Core Competencies

The areas I intend to develop include:

- Programming and software design
- Data structures and algorithms
- Mathematics for computer science and machine learning
- Databases and data engineering
- Operating systems and networking
- Backend and distributed systems
- Software testing and security
- Machine learning and deep learning
- AI systems architecture
- Model evaluation and experimentation
- Technical research and problem-solving
- Product development and deployment
